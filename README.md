# Linux Rice Configuration

Эта конфигурация предназначена для персонализации рабочего окружения на основе Linux Fedora. Основное внимание уделяется минимализму, эстетике и функциональности.

---

## 🔧 Основные компоненты

- **Rofi** — лаунчер приложений с настраиваемым интерфейсом.
- **Обои** — минималистичный пейзаж, гармонирующий с темой системы.
- **Скрипты настройки** — автоматизация установки и конфигурации окружения.

## Особенности
- 🎨 Современный дизайн в стиле Tokyo Night
- 📋 Быстрое копирование команд в буфер обмена
- 🔍 Удобный поиск по командам
- 📝 Простое добавление своих команд
- 🌈 Поддержка категорий команд
  
---

## 🚀 Установка

Для установки выполните следующие шаги:

```bash
# Клонируйте репозиторий
git clone git@github.com:seidenov/linux-rice.git

# Перейдите в папку с проектом
cd linux-rice

# Сделайте скрипт установки исполняемым
chmod +x install.sh

# Запустите скрипт установки
./install.sh
```
---

### Запуск
- Через терминал: `rofi -show cmds`
- Через горячие клавиши: настройте в вашем оконном менеджере

---

### Добавление своих команд
1. Откройте файл: `~/.config/rofi/scripts/commands.txt`
2. Добавьте команду в формате: `neofetch :: Информация о системе (где neofetch - команда, :: Информация о системе - информация о команде)`

---

### Как это работает
1. Выберите нужную команду из списка
2. Нажмите Enter для копирования в буфер обмена
3. Вставьте команду где нужно через Ctrl+V
