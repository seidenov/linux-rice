# Linux Rice Configuration

Эта конфигурация предназначена для персонализации рабочего окружения на основе Linux Fedora. Основное внимание уделяется минимализму, эстетике и функциональности.

---

## 🔧 Основные компоненты

- **Rofi** — лаунчер приложений с настраиваемым интерфейсом.
- **Обои** — минималистичный пейзаж, гармонирующий с темой системы.
- **Скрипты настройки** — автоматизация установки и конфигурации окружения.

---

## 🚀 Установка

Для установки выполните следующие шаги:

```bash
# Клонируйте репозиторий
git clone git@github.com:seidenov/linux-rice.git

# Перейдите в папку с проектом
cd linux-rice

# Сделайте скрипт установки исполняемым
chmod +x install.sh

# Запустите скрипт установки
./install.sh
```
