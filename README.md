# Linux Rice Configuration

Персональная конфигурация рабочего окружения Linux Fedora с акцентом на минимализм и эстетику.

## Компоненты
- Rofi (лаунчер приложений)
- Обои (минималистичный пейзаж)
- Скрипты настройки

## Установка

```bash
# Клонируйте репозиторий
git clone git@github.com:seidenov/linux-rice.git

# Перейдите в скачанную папку
cd linux-rice

# Сделайте скрипт установки исполняемым
chmod +x install.sh

# Запустите скрипт установки
./install.sh
